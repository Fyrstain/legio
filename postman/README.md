# Postman workflows

- `legio-lab-study/LegioLabStudy.postman_collection.json`: study, cohorting and datamart workflow.
- `ips-questionnaire/IPSQuestionnaire.postman_collection.json`: QuestionnaireResponse extraction workflow. See its README for endpoint requirements and validation limits.

The JSON fixtures in `ips-questionnaire/` are request bodies and an expected result for these workflows. Reusable standalone resource examples are defined in FSH under `ig/input/fsh/`.
