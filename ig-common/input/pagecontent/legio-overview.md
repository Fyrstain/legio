# Guides Legio

Legio publie deux guides d'implémentation FHIR :

- Le guide FHIR R4 décrit les patients, observations, questionnaires et bibliothèques CQL.
- Le guide FHIR R5 décrit les études de recherche, variables de preuve et l'extension Datamart.

Les guides sont construits séparément pour respecter leur version de FHIR. Ils partagent cette page de présentation, issue de `ig-common`. La page d'accueil commune du site publié donne accès aux deux guides.
